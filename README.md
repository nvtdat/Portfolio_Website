# Portfolio Website - Local Hosting with Caddy

## Steps
1. Installed Caddy with `winget install caddy`
2. Created a Caddyfile that serves static files on port 8080
3. Ran `caddy run` in the project folder
4. Opened http://localhost:8080 in the browser

## Files
- `Caddyfile`: server configuration
- `index.html`, `projects.html`, `articles.html`, `contact.html`: website pages
- `screenshots/`: evidence that the site is hosted successfully
